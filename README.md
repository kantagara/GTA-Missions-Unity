# Fully Modular Mission System in Unity - WIP
This is still WIP, as there are some more conditions and automations left to be done. 

## Mission System
This is a pretty robust and easily extandable Mission System similar to the ones you find in opne world games like GTA. The architecture also took some inspiration from [Isonzo](https://store.steampowered.com/app/1556790/Isonzo/), where I've developed the actual Challenges System.

### Mission Data
A single unit that represents the actual mission. It's characterized by a Mission Name, Mission Position (where you need to go to start it), Mission Steps, Conditions and Rewards.
